# Guitar Lab – 실용음악 · CCM 일렉기타 연습실

일렉기타 레슨용 웹 연습 사이트입니다. **왼손 / 오른손** 섹션을 나눠 따로 연습하고, **싱글노트**는 두 손 패턴을 합쳐 함께 연습합니다.

## 실행 방법
빌드가 필요 없는 정적 사이트입니다.
- `index.html`을 브라우저로 바로 열거나
- GitHub Pages(Settings → Pages → 브랜치 선택)로 배포하면 학생들이 링크로 접속할 수 있습니다.

## 구성
### 왼손 (`#left`)
- **9·11·13 텐션 지판** – 근음 · 코드 타입(maj7, m7, 7, m7(b5)) · 텐션(b9 9 #9 / 11 #11 / b13 13)을 고르면 지판 전체에 위치 표시, 어보이드 노트 안내, 실전 보이싱 다이어그램 & 재생
- **진행 속 텐션 보이싱** – Ⅱ–Ⅴ–Ⅰ, CCM Ⅳ–Ⅴsus–Ⅲm–Ⅵm 등 진행을 12키로 이조 · 반복 재생
- **텐션 퀴즈** – 음이름 맞히기 / 지판에서 찾기
- → 싱글노트 왼손 패턴 (양손 통합 섹션으로 이동)

### 오른손 (`#right`)
- **16비트 리듬 플레이어** – 16칸 그리드(↓↑ 피킹 방향 고정, 쉼 = 헛스트로크), 클릭으로 편집, 메트로놈/16분 클릭/스윙/템포 트레이너
- **패턴 라이브러리 & 랜덤 생성기** – CCM·펑크·싱코페이션 등 13가지 프리셋
- **음표 분리 연습** – 1·e·&·a 위치 분리, 누적, 액센트 이동, 16분음표 15가지 셀 자동 진행 드릴
- → 싱글노트 오른손 패턴 (양손 통합 섹션으로 이동)

### 싱글노트 – 양손 통합 (`#single`)
- **왼손 패턴**: 스케일 박스 / 3NPS / 한 줄 / 크로매틱 퍼뮤테이션, 시퀀스(3·4음 그룹, 3·4도 음정), 방향
- **오른손 패턴**: 8분·셋잇단·16분·6연음, 얼터네이트 · 16비트 모션 고정 · 다운 · 이코노미 · 레가토, 액센트, **오른손 섹션의 16비트 리듬 적용**
- 두 패턴을 합친 TAB(피킹 기호 · 액센트 · 카운트) 자동 생성, 재생 하이라이트, 인쇄

단축키: **스페이스바** = 현재 화면 재생/정지
